# RM200 측색계 (현재 Ver 0.31)

X-Rite RM200(팬톤 캡슈어) 측색계를 PC에서 쓰는 한국어 프로그램입니다. 새로고침 매장용.

## 받기 (새 PC)

1. **[RM200_setup.zip 받기](https://github.com/ds4eqm-lgtm/rm200-color/raw/main/download/RM200_setup.zip)** 를 눌러 받습니다.
2. 받은 파일을 오른쪽 단추로 눌러 [압축 풀기]를 합니다.
3. 풀린 폴더의 **RM200_측색계.bat** 을 두 번 누릅니다.
4. 처음이면 "설치하시겠습니까?"에서 [예] → 바탕화면 바로가기 등을 고릅니다.
5. 기계가 안 잡히면 "USB 드라이버를 한 번 바꿔야 합니다" 창에서 [지금 바꾸기] → Zadig의 [Install Driver].

한 번 설치하면 그다음 판부터는 켤 때 저절로 새 판으로 바뀝니다.
내 팔레트와 이색 장부는 공용 저장소에 있어 어느 PC에서 열어도 같습니다.
